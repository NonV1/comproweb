# TradingZone (starter)

This workspace contains a minimal starter for a Next.js frontend and FastAPI backend with Docker support.

Structure

- `frontend/` - Next.js (App Router, TypeScript, Tailwind)
- `backend/` - FastAPI

Run (developer)

1. Copy `.env.example` to `.env` and edit.
2. Start services with Docker Compose:

   docker-compose up --build
